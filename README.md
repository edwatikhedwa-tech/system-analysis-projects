# Проекты по системному анализу

Четыре учебных проекта, закрывающих разные этапы работы аналитика: работа с требованиями → проектирование API → пользовательские истории → постановка задачи разработчику.

> Учебные кейсы курса «Системный аналитик», Яндекс Практикум. Опубликованы только мои артефакты. Задания, теория, датасеты и материалы, разработанные другими авторами, не публикуются.

---

## Структура репозитория

| Папка | Проект | Что показывает |
| :--- | :--- | :--- |
| **[01-chatty-srs](01-chatty-srs/)** | Расширение спецификации требований мессенджера Chatty | Работа с чужой документацией: новый функциональный блок встроен в существующую SRS с сохранением нумерации и трассировки |
| **[02-api-modeling](02-api-modeling/)** | Моделирование профиля API для оформления страховки | Определение границ API, профиль операции, структура ответа |
| **[03-vita-backlog](03-vita-backlog/)** | Бэклог приложения для сети клиник «Вита» | Командная работа: DFD, карта пользовательских историй, критерии приёмки |
| **[04-otium-dev-task](04-otium-dev-task/)** | Постановка задачи разработчику для сервиса Otium | Правка контракта SOAP-интеграции, ревизия XSD-схем |
