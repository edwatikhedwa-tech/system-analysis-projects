# Chatty 2.0 — мои требования

Требования, которые я спроектировал и встроил в существующую спецификацию Chatty. Нумерация продолжает систему идентификаторов базового документа: `ВИ-` варианты использования, `Про-` производительность, `УИ-` удобство, `Над-` надёжность, `ДК-` доступность контента, `ПрИ-` программные интерфейсы, `Зав-` зависимости, `БП-` бизнес-правила.

> Спецификация Chatty 1.0 и начатая часть спецификации 2.0 разработаны другим аналитиком и предоставлены курсом — они не публикуются. Здесь только мои разделы.

---

## 1. Контекст доработки

Chatty — веб-приложение для изучения английского языка. Пользователи: ученики (изучают язык, посещают уроки, выполняют домашние задания) и преподаватели (проводят уроки, составляют задания, оценивают успеваемость).

К версии 2.0 добавлялась работа со словарём и карточками для изучения слов. Мой блок — **просмотр видеороликов с контекстным употреблением слова**: пользователь видит не только перевод и озвучку, но и живой пример использования слова в речи.

Ключевая сложность блока — внешняя зависимость. Видео приходит из подключаемой библиотеки, которой Chatty не управляет: библиотека может быть недоступна, ролик может не загрузиться, субтитров может не быть. Поэтому основной объём проработки ушёл в сценарии отказа и деградацию функциональности.

## 2. Вариант использования ВИ-11

| Поле | Значение |
| :--- | :--- |
| **Уникальный код и название** | ВИ-11: Просмотреть видеоролик с контекстным употреблением слова |
| **Контекст использования** | Просмотр видео в контексте использования изучаемого слова |
| **Область действия** | Веб-приложение Chatty |
| **Основное действующее лицо** | Преподаватель; Ученик |
| **Предусловие** | Успешно выполнен базовый сценарий ВИ-1 «Найти слово в словаре» |
| **Минимальные гарантии успеха** | Подключаемая библиотека отсутствует |
| **Гарантии успеха** | Видеоролик просмотрен |
| **Триггер** | Пользователь хочет просмотреть ролик, в котором используется изучаемое слово |

### Базовый сценарий

| Шаг | Действие |
| :--- | :--- |
| 1 | Пользователь выбирает нужное слово — система отображает список видеороликов, в которых встречается это слово |
| 2 | Пользователь включает воспроизведение — система начинает загрузку и буферизацию видео (< 10 с, Про-4) |
| 3 | Система отображает видеоплеер с выбранным роликом и запускает воспроизведение |

### Расширения

| Код | Ситуация | Поведение системы |
| :--- | :--- | :--- |
| **3а1** | Библиотека видео отсутствует | Система отображает обычную карточку со словом — текст и озвучка, без ролика. Пользователь возвращается к шагу 1 базового сценария либо переходит к просмотру подробной информации (ВИ-4) |
| **3а2** | Видео не загружается | Система показывает прогресс загрузки и предлагает перезагрузить ролик. При повторной неудаче — возврат к шагу 2. После третьей неудачной попытки система отображает текстовую карточку со словом и озвучкой (как в 3а1) |
| **3а3** | Субтитры отсутствуют | Система уведомляет об отсутствии субтитров и предлагает включить их, если они доступны в библиотеке, либо показать текстовую транскрипцию. При включении субтитров — возврат к шагу 3. Иначе пользователь переходит к озвучке (ВИ-2) или закрывает просмотр |

**Изменения в технологии и данных:** использовать подключаемую библиотеку видеофайлов с субтитрами по умолчанию.

## 3. Функциональные требования

### 3.1 Группа `Видео.Контекст` — просмотр видео с употреблением слова

| Требование | Формулировка | Трассировка |
| :--- | :--- | :--- |
| `.ПросмотретьВидеоролик` | Chatty должно загрузить видео из библиотеки и запустить видеоролик для изучения слов | ВИ-11; Про-3; ВИ-4; Над-2 |
| `.Закрыть` | Chatty должно закрыть ролик | ВИ-11; < 1 с, Про-3 |
| `.Ошибка` | Chatty должно после 3 безуспешных попыток (загрузка > 10 с) предложить пользователю текстовую карточку со словом и озвучкой | ВИ-11 3а2; Про-4; Над-1 |
| `.Кэширование` | Chatty должно выполнять временную буферизацию видеороликов для плавного воспроизведения в веб-версии и мобильных приложениях. Система может временно хранить видео, чтобы оно не прерывалось при просмотре, но не должна сохранять ролики постоянно и не должна давать возможность смотреть их без интернета | БП-5; Про-4 |
| `.Субтитры` | Chatty должно предлагать отображение субтитров к видеоролику и уведомлять, если субтитры отсутствуют | ВИ-11 3а3; Про-3; ПрИ-2 |

**Почему `.Кэширование` сформулировано так подробно.** Буферизация и постоянное хранение технически решаются одним и тем же механизмом, и разработчику естественно реализовать офлайн-просмотр «заодно». Но офлайн-доступ запрещён правообладателем (БП-5). Поэтому требование явно разделяет разрешённое (временное хранение фрагментов ради плавности) и запрещённое (постоянное хранение, просмотр без интернета).

### 3.2 Группа `Словарь.КарточкиИзучения` — работа с карточками

| Требование | Формулировка | Трассировка |
| :--- | :--- | :--- |
| `.ИзучениеСлов` | Chatty должно предоставлять возможность запустить quiz для изучения слов | ВИ-10; < 1 с на запуск, Про-3 |
| `.Ошибка` | Chatty должно отображать сообщение «Нет карточек для изучения» и предлагать добавить слово из словаря (кнопка «Добавить») | — |
| `.Добавить` | Chatty должно предоставлять добавление слова на карточку из словаря пользователя | ВИ-8; < 1 с, Про-3 |
| `.УжеДобавлено` | Chatty должно информировать: «Карточка уже создана для этого слова» | БП-1 |
| `.Удалить` | Chatty должно предоставлять удаление карточки из списка пользователя | ВИ-9; < 1 с, УИ-2 |
| `.Изучить` | Chatty должно предоставлять quiz по карточкам для проверки знаний | ВИ-10; < 3 с на карточку, Про-2 |
| `.ЗавершитьQuiz` | Chatty должно показывать итоги теста — процент правильных ответов, время прохождения — и отмечать «Верно / Неверно» для каждой карточки | ВИ-10 шаги 6–7; 99% успеха, УИ-3 |
| `.СохранитьСтатистику` | Chatty должно автоматически сохранять статистику в профиле пользователя: «Верно / Неверно», дату, прогресс | ПД-1 (хранение навсегда) |
| `.ПросмотрСтатистики` | Chatty должно отображать общую статистику в формате «выучено X из Y» | Расширение ВИ-10; < 1 с, Про-3 |

## 4. Нефункциональные требования

### 4.1 Производительность

**Про-4.** Воспроизведение видеоролика должно начинаться не позднее чем через 10 секунд после нажатия кнопки «Воспроизвести» при стабильном интернет-соединении со скоростью не ниже 5 Мбит/с. Система должна обеспечивать плавное воспроизведение без видимых задержек буферизации дольше 2 секунд подряд.

*Трассировка: ВИ-11; УИ-4; БП-5.*

### 4.2 Удобство использования

**УИ-4.** Веб-приложение должно обеспечивать плавное воспроизведение видео без прерываний за счёт буферизации и временной загрузки контента. Повторное воспроизведение ранее просмотренных роликов должно начинаться без задержки.

*Трассировка: ВИ-11; БП-5; Про-4.*

### 4.3 Надёжность

| Код | Требование | Трассировка |
| :--- | :--- | :--- |
| **Над-1** | Chatty должно успешно переключаться на текстовую карточку в 99% случаев после 3 неудачных попыток загрузки видео | ВИ-11 3а2 |
| **Над-2** | Chatty должно восстанавливать доступ к видеоконтенту в 95% случаев в течение 5 секунд после сбоя | Зав-3 |

### 4.4 Доступность контента

| Код | Требование | Трассировка |
| :--- | :--- | :--- |
| **ДК-1** | Chatty должно обеспечивать доступ к видеофайлам и субтитрам в 95% случаев при запросе в период с 9:00 до 18:00 | Зав-3 |
| **ДК-2** | Chatty должно уведомлять пользователя об отсутствии контента в 100% случаев в течение 1 секунды | ВИ-11 3а3; Про-3 |

## 5. Внешние интерфейсы и зависимости

### ПрИ-2. Подключаемая библиотека видеофайлов

**ПрИ-2.1** Chatty должно опрашивать подключаемую библиотеку видеофайлов для получения видео с контекстным употреблением слова, включая субтитры по умолчанию в формате `.srt` или аналогичном, если они доступны.

### Зав-3. Зависимость

Функциональность просмотра видео в контексте использования зависит от доступности видеофайлов в подключаемой библиотеке, включая субтитры по умолчанию.

## 6. Бизнес-правила

| ID | Правило | Тип | Характер | Источник |
| :--- | :--- | :--- | :--- | :--- |
| **БП-3** | При использовании видео в приложении необходимо указывать его источник и автора | Ограничение | Статическое | **Юридический отдел** |
| **БП-4** | Статистика по карточкам обновляется только после завершения quiz — нажатия «Завершить» | Правило обработки данных | Динамическое | Команда разработки ПО |
| **БП-5** | Chatty может временно хранить фрагменты видео для плавного воспроизведения, но не позволяет сохранять видеоролики постоянно и смотреть их без интернета | Ограничение | Статическое | **Юридический отдел** |
| **БП-6** | Если субтитры недоступны, Chatty должно уведомить пользователя в 100% случаев | Ограничение | Статическое | Команда разработки ПО |
| **БП-7** | Chatty должно ограничивать попытки загрузки видео тремя, после чего переключаться на текстовую карточку | Ограничение | Статическое | Команда разработки ПО |

**Источник — значимое поле.** БП-3 и БП-5 пришли из юридического отдела, а не от команды разработки. Разница принципиальная: техническое ограничение можно пересмотреть на архитектурном ревью, юридическое — нет. Без указания источника требование «не хранить видео постоянно» на первом же обсуждении превращается в «а давайте всё-таки сделаем офлайн-режим».

## 7. Термины, добавленные в глоссарий

| Термин | Определение |
| :--- | :--- |
| **Видео контекста** | Видеофайл (`.mp4`) с контекстным употреблением слова для обучения, получаемый из подключаемой библиотеки, включая субтитры по умолчанию (ВИ-11, Зав-3) |
| **Текстовая карточка** | Элемент интерфейса с текстом слова и озвучкой, отображаемый как альтернатива видео при ошибке загрузки (ВИ-11 3а1, ВИ-4) |
| **Субтитры** | Текстовое сопровождение видеоряда на языке оригинала или переводное, дублирующее и иногда дополняющее речь |
| **Кэширование** | Процесс временного хранения копий часто запрашиваемых данных в быстрой и легкодоступной области памяти — кэше |
| **Буферизация** | Процесс временного хранения данных в буфере, чтобы сгладить разницу в скорости между двумя устройствами или процессами, обменивающимися данными |
| **Статистика обучения** | Данные о прогрессе пользователя в формате «выучено X из Y», отображаемые после проверки знаний через карточки или видео |

Термины «кэширование» и «буферизация» внесены в глоссарий намеренно: в требовании `.Кэширование` они означают разные вещи, и без определений формулировка читается двусмысленно.
